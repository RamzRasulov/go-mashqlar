## Misol Sharti

a, b, c sonlari berilgan. Shu sonlardan eng kattasini toping.

### Namuna

Input: a=4, b=7, c=5
Output: katta son b=7

Input: a=9, b=3, c=10
Output: katta son c=10

Input: a=5, b=1, c=4
Output: katta son a=5

## Maslahat

Sonlarni taqqoslash uchun `if`, `else if`, `else` operatorlaridan foydalaning.

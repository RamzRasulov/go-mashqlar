## Misol sharti

a soni berilgan. Sonning musbat yoki manfiy ekanligini aniqlang. Son 0 ga teng bo'lsa, 0 ni konsolga chiqaring.

## Namuna

Input: a=4
Output: musbat

Input: a=-5
Output: manfiy

Input: a=0
Output: 0

## Maslahat

Sonni 0 bilan taqqoslang. Taqqoslash uchun if, else if, else operatorlaridan foydalaning.

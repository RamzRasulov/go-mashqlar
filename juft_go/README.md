## Misol sharti

Sonning juft yoki toqligini aniqlang. Agar juft bo‘lsa `juft` so‘zini chiqaring. Agar toq bo‘lsa `toq` so‘zini chiqaring.

## Namuna

Input: 4
Output: juft

Input: 7
Output: toq

Input: 18
Output: juft

## Maslahat

Sonning juft yoki toq ekanligini aniqlash uchun uni 2 ga bo‘ling.

Agar 2 ga bo‘lganda qoldiq 0 bo‘lsa, son juft.

Agar qoldiq 0 bo‘lmasa, son toq.
